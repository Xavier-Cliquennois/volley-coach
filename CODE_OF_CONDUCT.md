# Code of Conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## TL;DR

- Be kind. Be respectful.
- No harassment, discrimination, or personal attacks.
- Disagree on ideas, not on people.
- Maintainers can remove comments, commits, issues, or contributors that violate this code.

## Reporting

If you witness or experience unacceptable behavior, open a private issue or contact a maintainer.
